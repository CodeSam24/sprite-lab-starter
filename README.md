# Sprite Lab Starter (Day 3)

West-MEC Coding, Sprite Animation.

The page layout, colors, and both sprite sheets are already here. Your job:
put each sprite sheet inside a window, make the window hide the rest of the sheet,
then animate it with translate and @keyframes.

Every spot you write in is marked with a `YOUR CODE` comment, in `index.html` AND in `global.css`.

## Get the code

1. Open VS Code.
2. **File > Open Folder** and pick your class folder (where you keep your projects).
3. **Terminal > New Terminal**.
4. Type this and press Enter:

   ```
   git clone https://github.com/Xerrath/sprite-lab-starter.git
   ```

5. **File > Open Folder** and open the new `sprite-lab-starter` folder.
6. Right-click `index.html` and choose **Open with Live Server**.

## Files

- `index.html`: the page. Put the sprite sheets in at each `YOUR CODE` comment.
- `global.css`: the styles. Write your code under each `YOUR CODE` comment.
- `images/coin-spin.png`: a coin, 8 frames in one row. Each frame is 64px square.
- `images/byte-robot.png`: Byte the robot, 8 frames across and 4 rows (down, left, right, up). Each frame is 128px square.

Byte and the coin are original pixel art made for this class.
